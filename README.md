# ulacoder — portfolio v2

Personal site of Ulagat Nurtas (@ulacoder). Next.js 16 + Tailwind 4, EN/RU.

- All text lives in `src/lib/content.ts` (EN and RU side by side).
- Add a photo: put `public/me.jpg` and set `site.photo = "/me.jpg"`.
- Add a gallery: put images in `public/gallery/` and list them in `site.gallery`.

```bash
npm install
npm run dev
```

The previous version lives in [nurtas-ulagat-cv](https://github.com/ulacoder/nurtas-ulagat-cv) and stays untouched.
